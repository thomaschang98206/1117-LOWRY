1. Lowry 模型在做什麼？ 把「出口產業」變成整個城市

Lowry 模型是一種經濟基礎型的土地使用－交通互動模型。核心概念是： 基礎產業（例如出口導向工業、外來旅客等）帶進收入， 形成就業與人口；人口又會產生對各種 非基礎產業（服務、零售、地區性設施）的需求， 而這些活動必須在空間上找到落點，並受到距離與土地容量的限制。

整體架構（直覺版）
  • 輸入：各分區 基礎產業就業 \(E_i^B\)、土地面積 \(A_j\)、不可開發地 \(A_j^U\)、 基礎產業用地 \(A_j^B\)、空間阻隔 \(T_{ij}\) 等。
  • 第一層：基礎產業就業 \(\Rightarrow\) 全市就業 \(E\)、 戶數 \(N\)。
  • 第二層：用距離權重將 \(N\) 分配到各分區 \(N_j\)。
  • 第三層：由 \(N\) 推出各類非基礎產業總量 \(E^k\)， 再以空間阻隔＋基礎產業就業決定 \(E_i^k\) 在各地的分布。
  • 第四層：檢查最小規模、土地容量、住宅密度限制； 不符者調整後，重新回到第一層，直到收斂。
關鍵觀念：兩種就業 + 一個連鎖效果
  • 基礎產業 \(E_i^B\)：外來需求決定，視為外生。
  • 非基礎產業 \(E_i^k\)：由居民與就業人口需求內生決定。
  • 兩者合成總就業 \(E_i = E_i^B + \displaystyle\sum_k E_i^k\)， 再透過扶養戶數 \(f\) 轉為戶數 \(N\)。
出口導向 → 基礎就業 基礎就業 → 戶數 戶數 → 服務業 服務業再回頭增加就業
2. 變數與假設：看懂符號在代表什麼 先弄清主角是誰

原文裡有很多上標、下標與 k、i、j 的組合。這一節把它們整理成一張「角色表」， 之後看公式就比較不會迷路。

分區與就業
  • \(i\)：就業分區（工作地）；\(j\)：居住分區（住家）。
  • \(k\)：非基礎產業的種類，例如：
    • \(k=1\)：鄰里性服務（超商、小學…）。
    • \(k=2\)：地區性服務（醫院、大賣場…）。
    • \(k=3\)：都會性服務（大型百貨、專業服務…）。
  • \(E_i^B\)：第 \(i\) 區的基礎產業就業人數。
  • \(E_i^k\)：第 \(i\) 區、第 \(k\) 類非基礎產業就業人數。
  • \(E_i = E_i^B + \sum_k E_i^k\)：第 \(i\) 區總就業。
  • \(E^k = \sum_i E_i^k\)：全市第 \(k\) 類非基礎產業就業總量。
人口與戶數
  • \(N_j\)：第 \(j\) 居住分區的戶數。
  • \(N = \sum_j N_j\)：全市戶數總量。
  • \(f\)：每位就業人口所扶養的戶數（扶養比）。
土地與容量
  • \(A_j\)：第 \(j\) 區土地總面積。
  • \(A_j^U\)：不可發展土地（保護區、公共設施…）。
  • \(A_j^B\)：基礎產業使用的土地。
  • \(A_i^R\)：第 \(i\) 區非基礎產業用地需求。
  • \(A_j^H\)：可作住宅使用的土地： $$A_j^H = A_j - A_j^U - A_j^B - A_j^R$$
  • \(Z_j^H\)：第 \(j\) 區住宅最大密度（戶／土地單位）。
需求參數與空間阻隔
  • \(a^k\)：每一戶所產生之第 \(k\) 類非基礎產業就業人數。
  • \(e^k\)：第 \(k\) 類非基礎產業每一就業所需土地。
  • \(c^k,d^k\)：決定非基礎產業需求來源的權重，\(c^k+d^k=1\)。
    • \(c^k\)：「居民戶數」對第 \(k\) 類服務業的影響。
    • \(d^k\)：「就業人口」對第 \(k\) 類服務業的影響。
  • \(T_{ij}, T_{ij}^k\)：空間阻隔因素（例如通勤時間、成本）。
  • \(Z^k\)：第 \(k\) 類非基礎產業在一個分區可生存的最小規模。
3. 非基礎產業分配公式：\(E_i^k\) 怎麼來？ 看起來像機率，其實是分配權重

這一節對應原文 (4-3)、(4-3-1)、(4-3-2)、(4-3-3)。目標是決定： 第 \(k\) 類非基礎產業的總量 \(E^k\)，要分給每一個分區 \(i\) 多少？

3-1 原始分配式 (4-3)
\[ E_i^k = b^k\left[ \sum_{j=1}^{n} \left( \frac{c^k N_j}{T_{ij}^k} \right) + d^k E_i \right] \tag{4-3} \]
  • 括號內兩部分：
    1. \(\displaystyle\sum_j \frac{c^k N_j}{T_{ij}^k}\)：來自居民的需求， 距離越近（\(T_{ij}^k\) 小），貢獻越大。
    2. \(d^k E_i\)：來自就業人口本身的需求，例如上班地附近的餐飲。
  • \(b^k\)：調整因子，負責把這些「指數」縮放成真正的就業人數。

可以把括號內看成「第 \(i\) 區對第 \(k\) 類服務業的吸引力指數」， 越大表示越適合設第 \(k\) 類設施；\(b^k\) 則是把這些指數拉到 \(E^k\) 的實際規模。

把所有分區加總，可得 \[ \sum_{i=1}^{n} E_i^k = b^k \left[ \sum_{i=1}^{n} \sum_{j=1}^{n} \left( \frac{c^k N_j}{T_{ij}^k} \right) + d^k \sum_{i=1}^{n} E_i \right] = E^k \tag{4-3-1} \] 因此 \[ b^k = \frac{E^k}{\displaystyle \sum_{i=1}^{n} \left[ \sum_{j=1}^{n}\left(\frac{c^k N_j}{T_{ij}^k}\right) + d^k E_i \right]} \tag{4-3-2} \]
3-2 機率形式的分配函數 (4-3-3)
\[ E_i^k = E^k \cdot \frac{ \displaystyle \sum_{j=1}^{n} \left( \frac{c^k N_j}{T_{ij}^k} \right) + d^k E_i }{ \displaystyle \sum_{i=1}^{n} \left[ \sum_{j=1}^{n} \left(\frac{c^k N_j}{T_{ij}^k}\right) + d^k E_i \right] } \tag{4-3-3} \]

括號中的分數看起來就像一個「機率」：

  • 分子：第 \(i\) 區的吸引力指數。
  • 分母：全市所有分區的指數總和。
  • 因此各區指數的比重就是 \(E^k\) 分配到該區的比例。

這種寫法的好處：無論怎麼算，\(\sum_i E_i^k = E^k\) 一定成立， 不會因為四捨五入等問題，讓總量跑掉。

4. 居住人口與戶數：由就業推出戶數，再分到各區 「一份工作養幾戶人？」

接下來是 (4-5)、(4-6)、(4-7)、(4-8) 與 (4-8-3)。重點有兩步： 先用扶養比 \(f\) 把就業變成戶數，接著用距離權重 \(T_{ij}\) 把戶數分派到各居住分區。

4-1 各分區總就業與戶數
各分區總就業： \[ E_i = E_i^B + \sum_{k=1}^{m} E_i^k \tag{4-5} \] 全市戶數總量： \[ N = f \sum_{i=1}^{n} E_i \tag{4-7} \]

\(f\) 可以理解為：
每一位就業人口平均對應幾個「家戶」。 若一家裡有兩個人就業，\(f\) 就會小於 1。

4-2 戶數如何分到各區？
原式 (4-8)： \[ N_j = g \sum_{i=1}^{n}\frac{E_i}{T_{ij}} \tag{4-8} \] \(T_{ij}\) 越小（越近、越方便），該工作地對第 \(j\) 區的居住吸引力越強。
\(g\) 是調整因子，使得 \[ \sum_{j=1}^{n} N_j = N \tag{4-8-1} \] 因此 \[ g = \frac{N}{\displaystyle \sum_{j=1}^{n}\sum_{i=1}^{n}\frac{E_i}{T_{ij}} } \tag{4-8-2} \] 帶入後得到「機率形式」： \[ N_j = N\cdot \frac{\displaystyle\sum_{i=1}^{n}\frac{E_i}{T_{ij}}} {\displaystyle\sum_{j=1}^{n}\sum_{i=1}^{n}\frac{E_i}{T_{ij}}} \tag{4-8-3} \]

直覺上：\(\sum_i \frac{E_i}{T_{ij}}\) 可以看成 「從第 \(j\) 區出發，去所有就業地的便利度加總」，越大表示住在這裡越方便， 因此分配到的戶數就越多。

5. 土地面積與住宅密度限制 服務業也要占地、住宅有上限

當非基礎產業就業 \(E_i^k\) 決定後，就可以推算它們需要多少土地； 再加上不可開發地與基礎產業用地，就能知道剩下多少土地可給住宅使用， 並檢查密度是否過高。

5-1 非基礎產業用地需求 (4-6)
\[ A_i^R = \sum_{k=1}^{m} e^k E_i^k \tag{4-6} \]
  • \(e^k\)：第 \(k\) 類非基礎產業，每一就業所需土地，例如 1.9 \(\text{m}^2\)／人。
  • 因此 \(E_i^k\) 越大，該區非基礎產業用地 \(A_i^R\) 越大。
5-2 可用住宅土地與非負限制 (4-12)
可作住宅使用的土地： \[ A_j^H = A_j - A_j^U - A_j^B - A_j^R \tag{4-1重寫} \] 若有分區出現 \[ A_j^H \le A_j - A_j^U - A_j^B \tag{4-12} \] 代表住宅面積變成 0 或負值，表示土地被 非基礎產業「吃光」，此時必須令該區不再配置住宅。

在實作上，若 \(A_j^H\) 變成 0，即代表該區僅供 基礎與非基礎產業使用，不再新配住房。

6. 最小規模與住宅密度封頂 哪裡「撐不住」、哪裡「滿了」？

Lowry 模型除了距離與面積外，還有兩組關鍵限制： 非基礎產業最小規模 和 住宅最大密度。 前者會讓小規模服務業直接消失，後者則避免某區住宅塞太滿。

6-1 非基礎產業最小規模檢核 (4-10)
\[ E_i^k \ge Z^k \tag{4-10} \]
  • \(Z^k\)：第 \(k\) 類非基礎產業最小就業門檻。
  • 若某分區 \(E_i^k < Z^k\)，表示市場太小， 這類產業無法獨立生存，令 \(E_i^k = 0\)。

那原本分到這些「不足規模」分區的量怎麼辦？
原文做法：把不符合門檻的分區集合記為 \(W^R\)， 不在其中的分區重新計算一個 \(b'^k\)， 讓 \[ \sum_{i\notin W^R} E_i^k = E^k \tag{4-10-2} \] 也就是把原本要分給「撐不起來的分區」的量， 重新分攤到其他符合門檻的分區。

6-2 最大住宅密度檢核 (4-11)
\[ N_j \le Z_j^H A_j^H \tag{4-11} \]
  • \(Z_j^H\)：第 \(j\) 區住宅最高密度（戶／單位土地）。
  • 若 \(N_j\) 超過此上限，代表住宅太擁擠，必須被限制。

讓不符上限的分區集合記為 \(W^H\)， 對這些分區固定 \(N_j = Z_j^H A_j^H\)， 其餘分區用新的比例係數 \(g'\) 重新分配剩餘戶數，使 \[ \sum_{j\notin W^H} N_j = N - \sum_{j\in W^H} Z_j^H A_j^H \tag{4-11-2} \] 這樣一來，全市戶數總量仍維持 \(N\)，但擁擠分區被「封頂」了。

7. 完整操作流程：從輸入到收斂 一張表看懂所有步驟

這一節把所有公式串成一個「演算法流程」。實際操作時，只要照順序跑， 每一輪迭代都會更新 \(E_i, N_j, E_i^k, A_i^R, A_j^H\)， 直到結果不再明顯改變。

  1. 輸入資料： \(E_i^B, A_j, A_j^U, A_j^B, T_{ij}, T_{ij}^k, a^k, e^k, f, c^k, d^k, Z^k, Z_j^H\)。
  2. 收斂檢測值： 先用 (4-13)～(4-15) 算出 \(E^*, N^*, E^{*k}\)，作為最後的參考目標。
  3. 初始化 (Iteration 0)： 設 \(E_i = E_i^B\)、\(E_i^k=0\)、\(A_j^R=0\)。
  4. Step 1： 由 (4-5)、(4-7) 算出全市就業 \(E\) 與戶數 \(N\)。
  5. Step 2： 用 (4-8-3) 把 \(N\) 分成各區 \(N_j\)， 再用 (4-11) 檢查住宅密度，必要時調整為 (4-11-1)。
  6. Step 3： 用 (4-2) 算出各類非基礎產業總量 \(E^k = a^k N\)。
  7. Step 4： 用 (4-3-3) 算出各區非基礎產業就業 \(E_i^k\)， 再用 (4-10) 做最小規模檢核， 不符門檻的分區重新分配 (4-10-1)。
  8. Step 5： 以 (4-6) 算出 \(A_i^R\)，進而得到新的住宅土地 \(A_j^H\)， 檢查 (4-12) 非負限制。
  9. Step 6： 更新各區總就業 \(E_i = E_i^B + \sum_k E_i^k\)， 回到 Step 1 進行下一輪迭代。
  10. Step 7： 當 \(E, N, E_i^k, N_j\) 與上一次迭代的差距足夠小， 或接近 \(E^*, N^*\) 時，即視為收斂。
8. 範例 Ex.1：四分區城市操作示範（前兩次迭代） 把公式換成真正的數字

這個例子假設城市只有 4 個分區（1～4），預先給定基礎產業就業、土地面積、 空間阻隔因素，以及 3 種非基礎產業： 鄰里性(1)、地區性(2)、都會性(3)。 我們會依照前面各節的公式，一步一步跑到第二次迭代為止， 並說明每一步的意義與限制。

8-1 輸入資料：表 4-1、表 4-2 的意義
基礎產業就業與土地
基礎產業就業： \[ (E_1^B,E_2^B,E_3^B,E_4^B)=(500,1000,1500,2000) \] \[ E^B=\sum_{i=1}^4E_i^B=5000 \]
土地面積： \[ (A_1,A_2,A_3,A_4)=(2000,2000,2000,4000) \]
不可發展土地： \[ (A_1^U,\dots,A_4^U)=(10,10,10,20) \]
基礎產業用地： \[ (A_1^B,\dots,A_4^B)=(200,250,300,350) \]
  • 初始非基礎產業用地 \(A_j^R=0\)， 因此可作住宅的土地： \[ A_j^H = A_j - A_j^U - A_j^B = (1790,1740,1690,3630) \]
  • \(T_{ij},T_{ij}^k\)：4×4 的空間阻隔矩陣， 例：區 1 到 1、2、3、4 的值分別為 5、10、15、10 等。
非基礎產業參數
非基礎產業最小規模： \[ Z^1=30,\quad Z^2=100,\quad Z^3=200 \]
每戶產生的就業： \[ a^1=0.1064,\quad a^2=0.1808,\quad a^3=0.1206 \]
每就業所需土地： \[ e^1=1.9,\quad e^2=1.3,\quad e^3=0.08 \]
需求權重： \[ (c^1,d^1)=(0.9,0.1) \] \[ (c^2,d^2)=(0.7,0.3) \] \[ (c^3,d^3)=(0.5,0.5) \]
扶養戶數： \[ f=0.8504 \] 住宅最大密度： \[ Z^H=1.5 \]

這些參數會同時控制：城市總規模（透過 \(f,a^k\)）、 服務業是否能撐得住（透過 \(Z^k\)），以及 住宅是否爆量（透過 \(Z^H\) 與 \(A_j^H\)）。

8-2 收斂檢測值 \(E^*,N^*,E^{*k}\)
先用 (4-13) 算出理論平衡總就業： \[ E^* = E^B\left[1-f\sum_{k=1}^{3}a^k\right]^{-1} \] \[ E^* = 5000\left[1-0.85048(0.1064+0.1808+0.1206)\right]^{-1} \approx 7655 \]

之後每一輪算出的 \(E\) 都會拿來與 \(E^*\) 比較， 看城市規模是否逐步接近理論平衡。

由 (4-14)、(4-15)： \[ N^* = fE^* \approx 0.8504\times 7655 \approx 6510 \] \[ E^{*1} = a^1N^* \approx 693,\quad E^{*2}\approx 1177,\quad E^{*3}\approx 785 \]

這表示：若基礎產業維持 \(E^B=5000\)， 長期而言全市大約會有 6510 戶、三類服務業就業如上。

8-3 第一次迭代 (Iteration 1)：初始化
\[ E_i = E_i^B,\quad E = \sum_{i=1}^4 E_i^B = 5000 \] \[ N = fE = 5000\times 0.8504 = 4252 \] \[ E^k = 0\quad(k=1,2,3) \]

也就是說，城市一開始只有基礎產業，養出了 4252 戶居民， 服務業尚未出現。

住宅可用土地再確認一次： \[ (A_1^H,A_2^H,A_3^H,A_4^H)=(1790,1740,1690,3630) \]

後面所有密度檢核都會用到這組數字， 代表每區能接納住宅的空間大小。

8-4 居住戶數分派
用 (4-8-3)： \[ N_j = N\cdot \frac{\displaystyle\sum_{i=1}^4\frac{E_i}{T_{ij}}} {\displaystyle\sum_{j=1}^4\sum_{i=1}^4\frac{E_i}{T_{ij}}} \] 先算每一居住分區的吸引力： \[ \sum_{i=1}^4\frac{E_i}{T_{i1}}=100+100+100+200=500 \] \[ \sum_{i=1}^4\frac{E_i}{T_{i2}}=50+200+150+133=533 \] \[ \sum_{i=1}^4\frac{E_i}{T_{i3}}=33+100+300+200=633 \] \[ \sum_{i=1}^4\frac{E_i}{T_{i4}}=50+67+150+400=667 \] 全市總和： \[ \sum_{j=1}^4\sum_{i=1}^4\frac{E_i}{T_{ij}}=2333 \]
代入公式分配戶數： \[ N_1 = 4252\times\frac{500}{2333}\approx 911 \] \[ N_2 = 4252\times\frac{533}{2333}\approx 971 \] \[ N_3 = 4252\times\frac{633}{2333}\approx 1154 \] \[ N_4 = 4252\times\frac{667}{2333}\approx 1216 \]

第 4 區到各就業地都相對便利， 因此得到最大的戶數 \(N_4\)。

8-5 居住密度檢核
先算每區最大可容納戶數： \[ A_j^H\times Z^H =(1790,1740,1690,3630)\times1.5 =(2685,2610,2535,5445) \]
比較： \[ N_1=911<2685,\; N_2=971<2610 \] \[ N_3=1154<2535,\; N_4=1216<5445 \] 皆符合 (4-11) 限制。

所以這一輪不需要依 (4-11-1) 做重新調整。

8-6 非基礎產業總規模：\(E^k = a^k N\)
\[ E^1 = 0.1064\times4252\approx452 \] \[ E^2 = 0.1808\times4252\approx769 \] \[ E^3 = 0.1206\times4252\approx513 \]

表示在 4252 戶居民的需求下， 全市可以支撐約 452 人的鄰里性服務、 769 人的地區性服務、513 人的都會性服務。

8-7 非基礎產業在各分區的分布
以第 1 類（鄰里性）為例， 先算每一就業分區的吸引力指數： \[ I_i^1 = c^1\sum_{j=1}^4\frac{N_j}{T_{ij}^1} + d^1E_i \] 例如 \(i=1\)： \[ I_1^1 = 0.9\left( \frac{911}{5}+\frac{971}{10}+\frac{1154}{15}+\frac{1216}{10} \right) +0.1\times500 \approx480.02 \] 同理可得： \[ I_2^1\approx533.62,\; I_3^1\approx609.18,\; I_4^1\approx715.30 \] 總和約 \[ \sum_{i=1}^4I_i^1\approx2338.12 \]

對 \(k=2,3\) 也做同樣計算，只是改用 \((c^2,d^2)\)、\((c^3,d^3)\)， 分別得到總和約 2888.94、3492.10。

再用 (4-3-3) 分配： \[ E_i^k = E^k\frac{I_i^k}{\sum_i I_i^k} \] 以 \(k=1\) 為例： \[ E_1^1 = 452\times\frac{480.02}{2338.12}\approx93 \] \[ E_2^1\approx103,\; E_3^1\approx118,\; E_4^1\approx138 \] 對 \(k=2\) 得： \[ (129,170,215,256) \] 對 \(k=3\) 得： \[ (72,109,148,185) \]

可以看到第 4 區在各類產業中都是最大宗， 因為它的居民多、基礎就業也多。

8-8 最小規模限制：第三類服務業整體消失
\[ E_i^1=(93,103,118,138) \] \[ E_i^2=(129,170,215,256) \] \[ E_i^3=(72,109,148,185) \] 最小規模： \[ Z^1=30,\;Z^2=100,\;Z^3=200 \]
檢核： \[ E_i^1>30\Rightarrow\text{全部保留} \] \[ E_i^2>100\Rightarrow\text{全部保留} \] \[ E_i^3<200\Rightarrow E_i^3=0,\;\forall i \]

由於沒有任何分區的都會性服務業能達到 200 人， 這一輪就視為「都會性服務業尚未形成」。

8-9 更新各區就業與總量
重新加總三類非基礎產業： \[ E^1 = 93+103+118+138 = 452 \] \[ E^2 = 129+170+215+256 = 770 \] \[ E^3 = 0 \] 各區非基礎產業就業： \[ E_1^k=93+129+0=222 \] \[ E_2^k=103+170+0=273 \] \[ E_3^k=118+215+0=333 \] \[ E_4^k=138+256+0=394 \]
再加上基礎產業： \[ E_1 = 222+500=722 \] \[ E_2 = 273+1000=1273 \] \[ E_3 = 333+1500=1833 \] \[ E_4 = 394+2000=2394 \] \[ E = 722+1273+1833+2394 = 6222 \]

總就業已由 5000 增加到 6222， 但仍小於理論平衡值 \(E^*\approx7655\)， 因此還需要下一輪迭代。

8-10 第二次迭代 (Iteration 2) 的起始條件
依新的總就業 \(E=6222\)，再算一次戶數： \[ N = fE = 6222\times0.8504\approx5290 \quad(< N^*=6510) \] 非基礎產業用地 (4-6)： \[ A_1^R = 1.9\times93 + 1.3\times129 + 0.08\times0 \approx 344.4 \] \[ A_2^R \approx 416.7,\; A_3^R \approx 503.7,\; A_4^R \approx 595.0 \]
更新住宅土地： \[ (A_1^H,\dots,A_4^H) =(2000,2000,2000,4000) \] \[ -(10,10,10,20) \] \[ -(200,250,300,350) \] \[ -(344.4,416.7,503.7,595.0) \] \[ \approx(1445.6,1323.3,1186.3,3035) \]

這些值皆大於 0，符合 (4-12) 非負限制， 因此不需要進一步調整。接下來的 Iteration 2 就會以這組新的 \(E_i\)、\(A_j^H\) 再跑一次「\(E\to N\to E^k\to E_i\)」流程， 直到結果收斂。

9. Lowry 模型的限制與注意事項 怎麼用、又要對哪些地方保持懷疑

最後，把投影片中的注意事項整理成五點。這些並不是要否定 Lowry 模型， 而是提醒：模型只是簡化的世界，在解讀與應用時要保留空間給現實世界。

  1. 1. 靜態 (static)，不是動態 (dynamic)。
    Lowry 模型只能告訴我們在「某種條件下最終可能的平衡結果」， 不會描述發展過程中每一年、每一波投資的時序。 若研究重點是都市成長路徑或調適時序，需搭配其他動態模型。
  2. 2. 分派函數只看人口、就業與空間阻隔。
    真實生活中的居住／就業選擇還會受到收入、族群、偏好、公設品質、 治安、環境風險等影響；但基本 Lowry 模型裡不包含這些變數。 使用時要警覺：被忽略的因素可能放大或縮小某些差異， 需要以額外分析或情境討論補上。
  3. 3. 需求為主，供給限制多以「容量」間接表現。
    模型的重點在估計在某種戶數下產生多少服務需求， 而不是完整的市場供需均衡。 住宅供應、營建成本、資金與土地管制等供給面條件， 大多只透過「最大密度」和「土地非負」這類容量限制間接反映。
  4. 4. 全部建立在經濟基礎理論上。
    若某城市的發展並非由出口部門帶動， 或是非基礎產業本身也有大量外來需求， 則「基礎產業決定整體規模」的假設就會變得薄弱。 這時應重新檢視哪些產業被視為基礎、哪些被視為非基礎。
  5. 5. 空間阻隔因素 \(T_{ij}\) 被視為固定常數。
    在模型裡，\(T_{ij}\) 不會因為人口或產業重分布而改變； 但現實中，新建捷運、道路壅塞、票價調整都會大幅改變通勤成本。 此外，選擇用「時間」、「距離」、「成本」或其他指標來表示阻隔， 以及採用何種函數形式，都是非常關鍵但不容易決定的部分。

建議的使用方式是：把 Lowry 模型當成 情境比較與教學工具，用來看不同政策、 不同基礎產業配置大致會把人口與服務業推向哪裡； 真正做規劃決策時，仍要搭配更多統計、訪談與其他模型共同判讀。
